# 프록시 호환 계약 예제

실제 웹사이트를 이름으로 지정하거나 연결하지 않는 isolated-worker 프록시 호환 계층 예제입니다. 운영자가 승인한 Core service binding 하나만 사용하고 상대 경로만 허용하며 제한된 요청 헤더만 전달합니다. Cookie와 자격 증명은 전달하지 않고 리디렉션 및 Cookie 응답 헤더를 제거하며 8 MiB를 넘는 응답 본문을 거부합니다.

이 패키지는 계약과 보안 예제이며 공개 릴레이나 특정 상류 서비스의 추천이 아닙니다. 실제 어댑터를 공개하려면 별도의 대상 검토, 제한된 호스트 정책, 리디렉션 처리, 콘텐츠 재작성, 법적 검토 및 누출 회귀 테스트가 필요합니다.
