# 브라우저 브리지 플러그인

이름이 지정되고 취소 가능한 Browser Bridge 세션을 요청하는 패키지를 위한 분류입니다. 복사된 프로필 데이터, 제한 없는 자동화 또는 디버깅 엔드포인트를 제공하지 않습니다.

`browser-session-contract-example`은 SDK/Core 세션 계약을 위한 공개 픽스처이며 브라우저 드라이버나 상위 웹사이트를 포함하지 않습니다.

`uyous-media-contract`은 브라우저 보조 미디어 추출을 위한 T2 계약 예제입니다. Core가 관리하는 불투명 세션과 제한된 작업만 사용하며 Uyous 또는 실제 동영상 플랫폼 어댑터의 공개를 의미하지 않습니다.
