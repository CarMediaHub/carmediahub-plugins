# Browser Bridge Plugins

This category is for packages that request a named, revocable browser bridge session. A package does not receive copied profile data, unrestricted browser automation, or a debugging endpoint.

`browser-session-contract-example` is the public fixture for the SDK/Core session contract. It has no browser driver or upstream website.

`uyous-media-contract` is a T2 contract example for browser-assisted media extraction. It uses only Core-managed opaque sessions and bounded tasks; it is not a published Uyous or real video-platform adapter.
