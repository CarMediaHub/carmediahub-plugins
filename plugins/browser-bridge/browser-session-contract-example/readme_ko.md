# 브라우저 세션 계약 예제

이 격리 예제는 CarMediaHub의 불투명 브라우저 세션 계약을 검증합니다. 브라우저를 시작하지 않으며 Profile, Cookie, CDP, 호스트 경로 또는 임의 스크립트에 접근하지 않습니다.

`/session` 경로는 SDK를 통해 짧은 세션 메타데이터를 요청합니다. 통합 테스트용 픽스처이며 브라우저 자동화 기능이나 타사 사이트 어댑터가 아닙니다.

`/display` 경로는 SDK로 전달된 호스트 표시 기능(기기 유형, 입력 방식, 뷰포트, 전체 화면 지원)을 보여 주며, 전체 화면을 지원하지 않을 때 제어된 `unsupported` 결과를 시연합니다. 플러그인은 모드를 요청하고 결과를 읽을 수 있지만 브라우저 창, 프로필 또는 CDP를 제어할 수 없습니다.
