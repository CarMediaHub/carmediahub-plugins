# WDR 미디어

WDR 미디어는 차량용 화면을 위한 공식 미디어 전달 예제입니다. 운영자가 승인한 저장소, 미디어 작업, 카탈로그, 기록, 화면 기능과 차량 재생 상태를 조합하는 방법을 보여 줍니다.

이 패키지는 SDK 계약에 맞춰 구현하며 AList, rclone, FFmpeg 또는 다른 상류 프로젝트를 수정하지 않습니다. 미디어 소스는 Core 서비스 바인딩으로 설정합니다.

현재 패키지는 사용자와 설치 인스턴스별로 격리된 재생 기록을 포함합니다. Core는 저장소 핸들, 미디어 처리, 카탈로그 접근 및 서비스 바인딩을 제공하며, 플러그인은 데이터베이스 자격 증명, 상류 Cookie 또는 호스트 파일 시스템 경로를 받지 않습니다.
