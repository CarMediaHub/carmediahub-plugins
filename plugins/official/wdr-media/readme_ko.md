# WDR 미디어

WDR 미디어는 차량용 화면을 위한 공식 미디어 전달 예제입니다. 운영자가 승인한 저장소, 읽기 전용 Media Source, 미디어 작업, 카탈로그, 기록, 화면 기능과 차량 재생 상태를 조합하는 방법을 보여 줍니다.

이 패키지는 SDK 계약에 맞춰 구현하며 AList, rclone, FFmpeg 또는 다른 상류 프로젝트를 수정하지 않습니다. 미디어 소스는 Core 서비스 바인딩으로 설정합니다.

현재 패키지는 사용자와 설치 인스턴스별로 격리된 재생 기록과 direct-range 재생을 포함합니다. 스트림 요청은 `mode=remux` 또는 `mode=transcode`로 Core가 수행하는 변환을 선택할 수 있으며, `/hls?id=<미디어 ID>`는 단기 playlist 및 segment token을 사용하는 VOD HLS를 제공합니다. Worker는 미디어를 탐색하고 범위가 지정된 작업을 기다리며 논리 asset 경로만 다시 작성한 뒤 SDK로 asset을 청크 단위로 읽습니다. Core는 로컬 미디어 루트와 선택적 불투명 Media Source 핸들, 미디어 처리, 카탈로그 접근 및 서비스 바인딩을 제공하며, 플러그인은 데이터베이스 자격 증명, WebDAV 엔드포인트, 상류 Cookie, 호스트 파일 시스템 경로, FFmpeg 접근 권한 또는 명령 실행 권한을 받지 않습니다. 승인된 원격 소스는 `source` 진입 쿼리 값으로 선택하며 변환과 HLS는 Core가 관리하는 로컬 미디어에서만 사용할 수 있습니다.

서명된 패키지에는 검색, 직접 재생 및 전체 화면 명령을 갖춘 반응형 미디어 라이브러리 UI가 포함됩니다. Core는 로그인 후 전체 패키지 digest를 다시 검증한 경우에만 루트 문서와 `/ui/*` 자산을 서명된 패키지에서 제공합니다. UI는 Worker가 제공하지 않으며 패키지 경로를 노출하지 않습니다. 범위가 적용된 상태 확인 응답을 통해 현재 Core 언어를 상속합니다. 데스크톱, 휴대전화 및 차량 화면에서의 실제 재생 호환성은 지원 선언이 아니라 여전히 릴리스 검증 요구 사항입니다.

상태: `draft` · 분류: `official` · 런타임: `isolated-worker`
